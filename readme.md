# Printing Blogs

Code to index, fetch, rank, and format blog posts to be easy to print in one document, accompanying [this](https://fi-le.net/print). For print-ready documents, see the releases page.

Currently included are:
- [paulgraham.com](paulgraham.com)
- [marginalrevolution.com](marginalrevolution.com)
- [maxhodak.com](maxhodak.com)
- [guzey.com](guzey.com)
- [fi-le.net](fi-le.net)

Feel free to open a PR if you'd like to add another one.
